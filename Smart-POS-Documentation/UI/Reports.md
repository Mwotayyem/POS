# UI — Reports (شاشات التقارير)

> تصميم شاشات التقارير في **Smart ERP POS**. مبنية على **MVC + Bootstrap 5 + DataTables + Chart.js**. نمط موحّد: **فلاتر → جدول تفاعلي → تصدير**. تلتزم بـ [20-Reports.md](../20-Reports.md).

---

## 1) الهدف (Purpose)

تمكين المالك/المدير/المحاسب من تحليل الأداء (مبيعات، مشتريات، مخزون، أرباح، عملاء، موردون) بفلاتر مرنة، عرض جدولي/بياني، وتصدير احترافي (Excel/PDF).

---

## 2) قائمة التقارير (Report Catalog)

| التقرير | الوصف | الصلاحية |
|---------|-------|----------|
| مبيعات مجمّعة | حسب اليوم/الفرع/الكاشير | `reports.sales` |
| المنتجات الأكثر مبيعاً | ترتيب حسب الكمية/الإيراد | `reports.sales` |
| الأرباح | إيراد − تكلفة (هامش الربح) | `reports.profit` |
| حركة المخزون | كارت الصنف (In/Out) | `reports.inventory` |
| المخزون المنخفض | تحت حدّ الطلب | `reports.inventory` |
| المشتريات | حسب المورّد/الفترة | `reports.purchases` |
| أرصدة العملاء (AR) | مديونيات العملاء | `reports.finance` |
| أرصدة الموردين (AP) | مستحقّات الموردين | `reports.finance` |
| ملخّص الشفتات | إغلاقات + الفروقات | `reports.pos` |
| ضريبة المبيعات | إجمالي الضريبة للفترة | `reports.tax` |

## 4) لوحة الفلاتر (Filters Panel)

| الفلتر | النوع | ملاحظة |
|--------|------|--------|
| الفترة | منتقي تاريخ من/إلى + أزرار سريعة (اليوم/أمس/هذا الشهر) | إجباري |
| الفرع | multi-select | Owner فقط (المدير يُقيَّد بفرعه) |
| الكاشير/المستخدم | dropdown | لتقارير الأداء |
| التصنيف/المنتج | بحث تلقائي (Select2/AJAX) | للتصفية الدقيقة |
| الحالة | Completed/Draft/Returned | حسب التقرير |

- الفلاتر تُرسَل لـ endpoint التقرير الذي يستدعي SP مجمّعاً (انظر [StoredProcedures.md](../Database/StoredProcedures.md#3)).
- تُحفظ آخر فلاتر مستخدمة لكل مستخدم (Settings — Scope: User).

## 5) جدول DataTables

| الميزة | التفعيل |
|--------|---------|
| الفرز | لكل عمود (تصاعدي/تنازلي) |
| البحث الفوري | صندوق بحث + بحث لكل عمود |
| Pagination | من جهة الخادم (Server-Side) للجداول الكبيرة |
| التذييل | جمع/متوسط تلقائي للأعمدة الرقمية |
| الصفوف الملوّنة | تحذير للقيم الحرجة (خصم فرق شفت، مخزون منخفض) |
| RTL | نسخة DataTables RTL |

```javascript
$('#salesReportTable').DataTable({
  serverSide: true,
  ajax: { url: '/api/v1/reports/sales', data: filters },
  language: { url: '/lib/datatables/ar.json' },   // تعريب
  footerCallback: sumNumericColumns
});
```

## 6) التصدير (Export)

| الصيغة | الأداة | الاستخدام |
|--------|-------|-----------|
| Excel (.xlsx) | ClosedXML/EPPlus (خادم) | تحليل إضافي |
| PDF | QuestPDF/Rotativa (خادم) | طباعة رسمية بشعار المستأجر |
| طباعة | DataTables Print | نسخة سريعة |
| نسخ/CSV | DataTables Buttons | لصق سريع |

- التصدير من **الخادم** يحترم الفلاتر ويطبّق شعار/ترويسة المستأجر وتنسيق العملة.
- ملفات كبيرة تُولَّد كـ Background Job (Hangfire) ويُرسَل رابط التنزيل عند الجهوزية.

---

## 7) المخططات المرافقة (Inline Charts)

- كل تقرير يعرض مخطط اتجاه (Line/Bar) أعلى الجدول لتلخيص بصري.
- ألوان مشتقّة من هوية المستأجر.
- قابل للتصدير كصورة ضمن PDF.

---

## 8) الاستجابة (Responsive)

- على الجوال: لوحة الفلاتر تنهار لـ Accordion؛ الجدول قابل للتمرير الأفقي (`responsive` extension) أو يعرض تفاصيل الصف في modal.
- أزرار التصدير تتجمّع في قائمة منسدلة على الشاشات الصغيرة.

---

## 9) الأداء والأمان

- **الأداء:** التجميعات عبر SP + Covering Indexes؛ Server-Side pagination يمنع تحميل ملايين الصفوف؛ نتائج التقارير الثقيلة قابلة للتخزين المؤقت قصير الأمد.
- زمن استجابة مستهدف < 2s (p95).
- **الأمان:** كل تقرير مفلتر بـ `TenantId`؛ الفروع المرئية مقيّدة بصلاحية المستخدم؛ التصدير يُسجَّل في `AuditLogs` (من صدّر، ماذا، متى) لمنع تسريب البيانات.
