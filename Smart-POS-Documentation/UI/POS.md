# UI — POS (شاشة نقطة البيع)

> تصميم شاشة الكاشير في **Smart ERP POS**. مُحسَّنة لـ **السرعة** و**شاشات اللمس** و**اختصارات لوحة المفاتيح**. مبنية على **MVC + Bootstrap 5 + jQuery/AJAX**. تلتزم بمنطق [18-POS.md](../18-POS.md) و[API/Sales.md](../API/Sales.md).

---

## 1) الهدف (Purpose)

إتمام عملية بيع بأقل عدد نقرات وأسرع زمن ممكن (< 200ms للاستجابة). واجهة بسيطة يستخدمها الكاشير طوال اليوم، تعمل على شاشة لمس أو لوحة مفاتيح + ماسح باركود.

---

## 2) الشرط المسبق (Precondition)

- **شفت مفتوح** إجباري — عند الدخول بلا شفت، يظهر modal "فتح الشفت" (`openingCash`).
- الكاشير يُوجَّه لهذه الشاشة مباشرةً بعد الدخول.

## 4) منطقة المنتجات (Product Grid)

| العنصر | الوصف |
|--------|-------|
| حقل البحث/الباركود | مركّز تلقائياً (autofocus)؛ الماسح يكتب فيه ثم Enter |
| أزرار التصنيفات | فلترة سريعة أفقية (chips) |
| بطاقات المنتجات | صورة/أيقونة + اسم + سعر؛ نقرة = إضافة للسلّة |
| شبكة متجاوبة | 4–6 أعمدة حسب عرض الشاشة، أزرار كبيرة للمس |

- **مسح الباركود:** `GET /products/barcode/{code}` → إضافة فورية للسلّة (< 50ms).
- **البحث النصّي:** `GET /products/search?q=` مع debounce 200ms.

---

## 5) السلّة (Cart Panel)

| العنصر | الوظيفة |
|--------|---------|
| سطر الصنف | اسم + كمية + سعر الوحدة + الإجمالي |
| ± الكمية | أزرار زيادة/نقصان أو إدخال مباشر |
| حذف الصنف | زر × لكل سطر |
| الخصم | خصم على السطر أو الفاتورة (% أو مبلغ) |
| ملخّص الإجماليات | المجموع، الخصم، الضريبة، الإجمالي، **المتبقّي/الباقي** |
| العميل | اختيار عميل (للآجل/الولاء) — اختياري |

- الإجماليات تُعاد حسابها فوراً في المتصفّح ثم تُؤكَّد من الخادم عند الدفع.

## 6) نافذة الدفع (Payment Modal)

```
┌─────────────────────────────────┐
│  الإجمالي المستحق:    19.14     │
│  ┌────────┐┌────────┐┌────────┐ │
│  │💵 نقد  ││💳 بطاقة││📱 محفظة│ │
│  └────────┘└────────┘└────────┘ │
│  المبلغ المدفوع: [____20.00___] │
│  الباقي للعميل:        0.86     │
│  [أرقام سريعة: 20|50|100|مضبوط] │
│  ┌───────────────────────────┐  │
│  │   تأكيد الدفع (Enter)     │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

- **دفع متعدّد الطرق:** إضافة أكثر من طريقة (نقد + بطاقة) — يعكس بنية `Payments` (انظر [API/Sales.md](../API/Sales.md#4)).
- عند التأكيد: `POST /sales/invoices` (ذرّي) → طباعة الإيصال → مسح السلّة → تركيز حقل الباركود.
- أزرار المبالغ السريعة تسرّع البيع النقدي.

## 7) اختصارات لوحة المفاتيح (Keyboard Shortcuts)

| المفتاح | الوظيفة |
|---------|---------|
| `F2` | تركيز حقل البحث |
| `F4` | تعليق الفاتورة (Suspend) |
| `F5` | استئناف فاتورة معلّقة |
| `F9` | فتح نافذة الدفع |
| `F10` | دفع نقدي سريع (مبلغ مضبوط) |
| `+ / -` | زيادة/نقصان كمية آخر صنف |
| `Delete` | حذف الصنف المحدَّد |
| `Esc` | إلغاء الفاتورة الحالية |
| `Ctrl+P` | إعادة طباعة آخر إيصال |

> الاختصارات ضرورية للكاشيرين المحترفين (سرعة أعلى من اللمس).

---

## 8) الفواتير المعلّقة (Suspend / Resume)

- **تعليق (F4):** يحفظ snapshot في `SuspendedInvoices` مع تسمية اختيارية (مثل "الطاولة 5") ويمسح السلّة.
- **استئناف (F5):** يعرض قائمة المعلّقة → اختيار → إعادة بناء السلّة من الـ snapshot.
- مفيد للمطاعم (طاولات) والبيع المتزامن لعملاء متعدّدين.

---

## 9) دعم شاشة اللمس (Touch UX)

| المبدأ | التطبيق |
|--------|---------|
| أزرار كبيرة | ≥ 60×60px لبطاقات المنتجات وأزرار الدفع |
| بلا hover | كل التفاعلات بالنقر/اللمس |
| لوحة أرقام | On-screen numpad لإدخال الكميات والمبالغ |
| تغذية راجعة | تأثير بصري + صوت عند إضافة صنف |
| منع التمرير العرضي | تخطيط ثابت بلا scroll أفقي |

---

## 10) معالجة الأخطاء (Errors)

| الحالة | العرض |
|--------|-------|
| باركود غير معروف | Toast "باركود غير معروف" + صوت تنبيه |
| مخزون غير كافٍ | تحذير عند الإضافة أو رفض عند الدفع |
| لا شفت مفتوح | إجبار فتح شفت أولاً |
| انقطاع الشبكة | وضع "معلّق محلياً" + إعادة مزامنة (offline-tolerant) |

---

## 11) الأداء والأمان

- **الأداء:** بحث الباركود يستخدم `UX_ProductBarcodes_Tenant_Barcode`؛ إنشاء الفاتورة p95 < 200ms.
- كاش محلي لكتالوج المنتجات النشطة (يقلّل طلبات الشبكة).
- **الأمان:** كل عملية مرتبطة بـ `shiftId` و`userId` للتدقيق؛ العزل بـ `TenantId`/`StoreId` تلقائي؛ حركات الصندوق تُسجَّل في `CashDrawerMovements` للمطابقة عند الإغلاق.
