# UI — Settings (شاشات الإعدادات)

> تصميم شاشات الإعدادات في **Smart ERP POS**. مبنية على **MVC + Bootstrap 5** بنمط **تبويبات (Tabs)**. تُمكّن المستأجر من التخصيص الكامل (شعار/ألوان/عملة/ضريبة/لغة/قوالب طباعة) **دون إعادة نشر** — تجسيداً لمبدأ *Configuration over Code*. تلتزم بـ [23-Settings.md](../23-Settings.md) و[24-MultiTenant.md](../24-MultiTenant.md).

---

## 1) الهدف (Purpose)

لوحة تحكّم شاملة يضبط منها المالك/المدير هوية الشركة، القواعد المالية، وسلوك النظام لكل مستأجر وفرع — بحيث تخدم النواة الواحدة آلاف العملاء بلا تعديل كود.

---

## 2) الصلاحيات ونطاق الإعداد (Scope)

| النطاق (Scope) | من يعدّله | يُخزَّن في |
|----------------|-----------|-----------|
| Tenant | Tenant Owner | `TenantSettings` |
| Store | Store Manager | `StoreSettings` |
| User | كل مستخدم | `Settings` (Scope: User) |

- الإعداد الأدنى (Store/User) يتجاوز الأعلى (Tenant) عند التعارض (Override).

---

## 3) التخطيط — تبويبات جانبية (Tabbed Layout)

```
┌──────────────────────────────────────────────────────────────┐
│  ⚙️ الإعدادات                                    [حفظ الكل]  │
├───────────────┬──────────────────────────────────────────────┤
│ 🏢 عام        │  ── محتوى التبويب النشط ──                   │
│ 🎨 الهوية      │                                              │
│ 💰 المالية     │   [نموذج الإعداد بحقوله]                     │
│ 🧾 الطباعة     │                                              │
│ 🌐 اللغة       │                                              │
│ 👥 المستخدمون  │                                              │
│ 🔐 الأمان      │                                              │
│ 🏬 الفروع      │                                              │
│ 🔌 التكاملات   │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- تبويبات عمودية (`nav-pills flex-column`) على اليمين (RTL)، المحتوى في `tab-content`.
- كل تبويب نموذج مستقل يُحفَظ عبر AJAX (بلا إعادة تحميل الصفحة).

## 4) تبويب: عام (General)

| الحقل | النوع | ملاحظة |
|-------|------|--------|
| اسم الشركة | نص | يظهر في الفواتير |
| نوع النشاط (Business Type) | dropdown | يفعّل ميزات القطاع (Feature Flags) |
| الرقم الضريبي | نص | للفواتير الرسمية |
| العنوان / الهاتف | نص | ترويسة المستندات |
| المنطقة الزمنية | dropdown | تواريخ العرض (التخزين UTC) |

## 5) تبويب: الهوية البصرية (Branding)

| العنصر | الأداة | القيد |
|--------|-------|------|
| رفع الشعار | Drag & Drop / File Upload | PNG/SVG، ≤ 1MB، معاينة فورية |
| اللون الأساسي | Color Picker | `PrimaryColor` — يُطبَّق على النظام كله |
| اللون الثانوي | Color Picker | للتأكيدات والمخططات |
| خلفية الدخول | رفع صورة/تدرّج | شاشة Login |
| قالب الإيصال | معاينة حيّة | يعكس الشعار واللون |

```javascript
// معاينة حيّة: تحديث متغيّرات CSS فور اختيار اللون
colorPicker.on('change', (color) => {
  document.documentElement.style.setProperty('--brand-primary', color);
  livePreview.refresh();   // معاينة الإيصال/الواجهة فوراً
});
```

- الشعار يُرفع لتخزين آمن (Blob/S3) ويُحفَظ رابطه في `TenantSettings.LogoUrl`.
- التغييرات تنعكس فوراً بعد الحفظ بلا إعادة نشر (تُقرأ من `TenantSettings`).

## 6) تبويب: المالية (Finance)

| الحقل | النوع | ملاحظة |
|-------|------|--------|
| العملة | dropdown (ISO 4217) | `CurrencyCode` |
| رمز/موضع العملة | نص | قبل/بعد المبلغ |
| نسبة الضريبة الافتراضية | رقم % | `DefaultTaxRate` |
| الضريبة شاملة/مضافة | toggle | Inclusive/Exclusive |
| تقريب المبالغ | dropdown | لأقرب 0.05/0.01 |
| بادئة أرقام المستندات | نص | لكل نوع (INV-/PUR-) → `Sequences.Prefix` |

> الأموال دائماً `DECIMAL(18,4)` — انظر [04-Database-Design.md](../04-Database-Design.md).

## 9) تبويبات إضافية

| التبويب | المحتوى |
|---------|---------|
| المستخدمون | إدارة المستخدمين، الأدوار، الصلاحيات (RBAC) |
| الأمان | سياسة كلمة المرور، 2FA، مدّة الجلسة |
| الفروع | إضافة/تعديل الفروع والمستودعات |
| التكاملات | مفاتيح API، الطابعات، بوابات الدفع، e-Invoicing |

---

## 10) التحقق والحفظ (Validation & Save)

| البند | القاعدة |
|-------|---------|
| رفع الشعار | نوع/حجم مقبول، أبعاد مناسبة |
| اللون | صيغة HEX صحيحة |
| الضريبة | 0–100% |
| العملة | من قائمة ISO المعتمدة |
| الحفظ | AJAX لكل تبويب → Toast نجاح/فشل |
| التزامن | `ConcurrencyStamp` يمنع الكتابة فوق تعديل آخر |

---

## 11) الأداء والأمان

- **الأداء:** الإعدادات تُقرأ مرة وتُخزَّن مؤقتاً (Cache) لكل مستأجر؛ تُبطَل الذاكرة المؤقتة عند الحفظ.
- **الأمان:** كل تعديل مفلتر بـ `TenantId`؛ فقط الأدوار المخوّلة تعدّل نطاق Tenant؛ كل تغيير يُسجَّل في `AuditLogs` (القيمة القديمة/الجديدة) للتدقيق الكامل؛ رفع الملفات يُفحَص (نوع/حجم/محتوى) لمنع الرفع الخبيث.
